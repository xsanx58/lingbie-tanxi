# 《临别叹息》· 丧尸末世生存模拟

一款依据设计文档《末世残响 · 超高自由度丧尸末》制作的**浏览器单机生存游戏**。无需安装、无需联网，双击打开即可游玩。

## 如何开始

双击 `index.html`，用任意现代浏览器（Edge / Chrome / Firefox）打开即可。

想分享给别人玩、或部署成可更新的在线版？见 [发布指南.md](发布指南.md)：支持局域网直连、itch.io、GitHub Pages 三种方式，游戏内置「检查更新」。

在标题页创建角色（姓名、职业、身体状况、开局时间、资源、异能、死亡模式），点击「进入末世」开始；刷新页面后可通过「继续上次的人生」接着玩。

## 游戏目标

没有固定主线。你可以：

- 只是想活过今晚
- 一个人流浪求生
- 搜刮物资、寻找家人
- 建立安全屋，发展成营地、城镇乃至新城市
- 招募幸存者、研究感染、寻找解药
- 当商人、掠夺者，或新文明的缔造者

活下来是第一原则。世界不会围着你转：资源有限、感染会恶化、丧尸会进化、人类会重新组织。

## 核心系统

- **时间**：每天分清晨 / 白天 / 黄昏 / 夜晚 4 个时段，每次行动消耗时段；夜晚更危险。
- **生存**：生命、体力、饥饿、口渴、疲劳、体温、精神、士气，9 项状态互相影响。
- **感染**：暴露 → 潜伏 → 初期 → 中期 → 重度 → 临界。主角天生带有特异抗体：感染会缓慢自行回落、不会直接致死；服用抗生素或消毒剂可主动清除病毒。
- **战斗**：近战 / 枪械、潜行、逃跑。枪声与打斗会引来更多丧尸——要同时想“打完以后怎么办”。
- **探索与搜刮**：平阳、临江两城共 22 个地点，每次搜索必有收获、可反复搜索；警察局、军营、加油站、物流仓库、药店、医院、农场等地有高概率特产。
- **基地**：安全屋 → 营地 → 防御基地 → 城镇 → 新城市。15 种设施可建造（含健身房），招募幸存者并安排守卫 / 拾荒 / 种植 / 医护 / 维修岗位。
- **世界演化**：异常期 → 爆发期 → 崩坏期 → 失序期 → 割据期 → 进化期 → 重建期 → 新世界，尸潮、天气、掠夺者、商队、军方广播、求救信号都会自行发生。
- **异能**：稀有而强大，会随使用成长，也有代价。
- **死亡与继承**：默认真实死亡；死亡后可由基地中的幸存者继承，继续同一世界。也可开启“可回档”模式。
- **结局**：生存、家园、城镇、文明、隐居、新世界……以及无数种死法。

- 左侧：生存状态面板。
- 中部六个页签：行动 / 地图 / 背包 / 基地 / 团队 / 日志。
- 右侧：最近动态。

- 顶部按钮：「修改器」（内置作弊面板，平时隐藏，点击才打开）。

## 内置修改器

点击游戏右上角的「🛠 修改器」打开，点「隐藏修改器」或右上角 × 收起。

- **物品**：选择「玩家背包 / 基地仓库」，可添加、设定为指定数量或清除任意物品；也有一键快捷按钮（+50 瓶装水、+50 罐头、+20 木板/金属/零件、+10 燃油/绷带/抗生素等）。
- **人物状态**：直接修改生命、体力、饥饿、口渴、疲劳、体温、精神、士气、感染、免疫力、负重加成与现金，支持一键满状态、清除伤口、清除感染。
- **添加帮手**：自选姓名、性别、年龄、职业（决定基础技能）、岗位、异能，以及生命 / 士气 / 忠诚 / 近战 / 远程数值。岗位中的「跟随」会陪你外出并肩战斗，「守卫」负责保卫基地。
- **基地**：立即建立基地、完成所有在建建筑、防御 +20、士气设为 80。

## 奇遇系统

每次行动约有 **5%** 概率触发奇遇（在行动/赶路/过夜等时间推进时判定）。

- **剧情事件**：巷口的孩子、白大褂的研究员、军车旁的铁箱、受伤的掠夺者、教堂的钟声、屋顶上的老人、地下室的敲击声、水井旁的对峙、松动的石板……每个事件都有多个选项，选择会带来物资、状态、阵营关系、道德标签等不同结果，部分选择还会引发后续剧情。
- **奇遇任务**：部分奇遇会是一个完整的委托——你会先遇到委托人，了解他的故事，然后接到一个要去特定地点完成的使命。顶部「奇遇」栏目会记录目的地和进度；到达目标地点后，行动页会出现「奇遇」按钮，点击即可开启多段剧情（对话、回忆、探索），完成后获得物资奖励。部分奇遇的奖励是一位强力的新同伴——他/她会带着自己的技能与武器加入你的团队。
- **特殊人物**：共 **50 位**有姓名、背景、阵营（友好 / 中立 / 敌对）和好感度的独立人物。遇见后可以：
  - 📖 了解背景（随时间与相处逐渐解锁完整故事）
  - 💬 交谈（每天一次提升好感度）
  - 🎁 索要物资（好感越高成功率越高，满好感必定成功）
  - 🔁 交换物资（各取所需）
  - 📜 接受并完成任务（交付物资 / 前往地点 / 猎杀丧尸），完成后大幅提升好感并获得奖励
  - 🤝 招募入队（好感与态度共同决定成功率；敌对人物会随好感提升逐渐改变态度）
- 人物会在世界上活动：他们的背包物资和所在地会随时间实时变化，地图上用 🧭 标出。
- **结局**：共 10 种结局（生存、隐居、城镇、文明、科研、救世、垄断、战争、巨贾、新世界）。满足条件时可选择“接受结局”收尾，或继续生存探索其他结局；菜单里可随时查看「结局图鉴」。

## 长线扩展

- **人物支线**：22 位特殊人物招募入队后，在「团队」页会多出「支线」按钮。每人有一条属于自己的入队后剧情（送物资 / 去地点 / 猎杀丧尸），完成后有奖励和一句收束人生的结局；全部收录在「成就 / 人物志」里。
- **阵营剧情**：军方残部、商队、掠夺者、守望者教会、企业避难所各有三段式剧情，声望达标后自动推进。最后可以选择加入某一方（此后每 15 天有阵营补给），或保持独立。
- **解药主线**：触发研究后按“采集样本 → 建病毒实验室 → 保卫实验室 → 疫苗诞生”推进，最终可选公开 / 私藏 / 交给军方，对应三种走向（其中公开与私藏是独立结局）。
- **载具**：奇遇可获得越野车。开车赶路更快，但耗油、有噪音、车况差会抛锚；可修理、加油，后备箱 60 kg 独立储物。
- **发电机**：开启开关后自动消耗仓库燃油（每天 1 份）持续供电；燃油耗尽自动暂停，仓库里重新有油后自动重启，无需手动加油。
- **季节**：春夏秋冬每季 90 天。冬天更冷、更饿、菜园减产；夏天更热、更渴、菜园增产。
- **进化与战争**：按世界天数推进（见下表），旧存档载入时会自动按当前天数补齐进度。
- **氛围与工具**：环境音效（风声/电台杂音/远处尸吼，可开关）、16 项成就、3 个存档位、奇遇频率设置（3% / 5% / 8%）。

## 通讯、双城与武器

- **双城地图**：地图分为平阳市（A 市，你的出发地）与临江市（B 市）。跨城路程更长、开车油耗更高。五方阵营分驻两城：军方与商队在平阳，掠夺者、守望者教会、企业避难所在临江。
- **随身无线电**：获得「随身无线电」后（富余开局自带，也能搜刮得到），行动页会出现「通讯系统」：
  - 联系阵营接取任务（送物资 / 猎杀 / 侦察三种）
  - 指派营地成员代送物资任务，送达后奖励自动存入仓库并通知你；也可以亲自送到阵营驻地自动结算
  - 结识过的人会偶尔通过无线电求助（有冷却时间，不会刷屏）；你随时可以主动「询问近况」，他们会告诉你最近的经历、位置、携带的物资和好感度
- **载具修理**：「快速修理套件」可一键把车修到完好；「机械亲和」异能者（自己或团队中的成员）会每天自动保养车辆，半路抛锚时跟随的机械师会直接修好并告诉你。
- **阵营特色商店**：联系任意阵营都有各自的商店——军方「军需处」卖子弹、枪械与火药弹壳；商队「农贸商店」卖种子、肥料、饲料与牲畜；掠夺者「黑市」卖刀、燃油；教会「救济站」卖食物药品；企业「科技商店」卖电池、零件与医疗品。伤害越高的武器价格越高，稀有武器也可通过困难任务获得（见下表）。
- **子弹复装**：在基地工坊用「火药 + 弹壳 + 铅块」复装手枪弹 / 步枪弹。三种材料都能搜刮到，军营与警察局概率最高。

## 搜刮与农事

- **搜刮规则**：每次搜索都必有收获，可以反复搜索，不再有“可搜次数”。现金是通用物资，任何地区都可能翻到（80% 概率 ¥50–100，20% 概率 ¥100–500）；部分地区有高概率特产（70%）：警察局特产子弹、火药、弹壳，军营特产步枪弹与军粮，加油站特产燃油，物流仓库特产木板、金属等建材，药店医院特产药品，南郊农场特产种子、肥料、家禽，柳河村特产小麦、玉米、饲料，山城小镇特产羊毛、牲畜，滨江码头特产燃料与零件等。特产材料在其他地区也能搜到，只是概率较低。
- **加油站抽油**：在城郊加油站行动页可「抽取燃油」，每次 5–10 桶；油泵噪音有 60% 概率引来大群丧尸围攻。
- **农场与牧场**：基地可建造「农场」「牧场」（另有入门级的菜园、鸡舍）。农场种植玉米/小麦/土豆，牧场养殖鸡/猪/牛/羊。
  - 作物需要每天**一键浇水**，牲畜需要每天**一键喂水**——用的是无限自来水，和饮用水完全分开，不消耗任何资源。
  - **肥料**加速作物生长，**饲料**加速牲畜生长；两者都可以在农贸商店购买，也可以在基地制作（沤制肥料、配制饲料）。
  - 作物成熟后一键收获；牲畜长大后持续产出（鸡蛋 / 猪肉 / 牛奶 / 羊毛）。
- **农民与牧民异能**：「绿手指」自动打理农场（每天浇水、成熟即收、自动补种、长得更快），「牧语者」自动照料牧场（喂水喂食、加速生长、收集产出）。和机械亲和一样，自己或团队成员拥有即可生效，无需手动操心。
- **健身房**：基地设施。每天最多锻炼 4 次，每次提升 1kg 负重上限，永久生效、每日刷新次数。
- **堆肥桶**：基地设施。把食物（变质食物也可以）投进去，发酵 2 个时段（约半天）后自动变成肥料——支持一次多投（+1 / +5 / 全部），也能一键把全部变质食品投入。
- **NPC 物资管理**：待在基地的成员不随身带物资，统一使用仓库。出门时按路途天数自动打包口粮、饮水（有伤按天数带绷带），捡到的东西除武器外全部直接入库，武器留给自己；送达或回到基地后，没用完的物资自动归还仓库，并用仓库里的药品自动恢复生命、士气。

## 团队与 NPC 管理

- **开局伙伴「星期五」**：开局就会在破旧公寓遇到他。建立安全屋时若在公寓，他会主动成为守卫；平时状态尚可时会自行出门搜集建材、水和食物，有伤则留在基地养伤。
- **团队页「管理」**：每位成员都可以查看状态与随身背包、谈话、从基地仓库给他装备 / 更换 / 卸下武器。
- **跟随**：把成员设为「跟随」岗位，他/她就会陪你外出并肩战斗，出门时自动按路途打包口粮。
- **探索任务**：给成员安排指定物资的搜索任务（可多选），他/她每天外出寻找目标资源；状态不佳时不会硬撑，会主动折返基地养伤。
- **自主行为**：待命成员没任务时会自己出门探索（有伤或状态差则留在基地休息）；基地成员也可能在外结识其他幸存者，处得好会把人带回基地。

## 战斗场景

遭遇丧尸时是完整的战斗场景：左侧敌人（类型、数量、血量条、噪音条）、右侧自己（生命条、武器、弹药）与并肩作战的队友（名字、武器、生命），下方是滚动战斗日志。**团队成员的武器会真实计入伤害**：跟随者持刀枪会一起输出，守卫持武器会提高基地防御；拾荒者也可能捡到武器防身，特殊人物入队时会带上自己最好的武器。

## 提示

1. 开局先找水和食物，别贪枪声。
2. 受伤尽快用绷带处理，被咬后立刻用消毒剂。
3. 夜晚尽量待在室内休息。
4. 建立基地后先造水井和菜园，再想围墙。
5. 人本身就是资源：一个电工可能比一个战士更值钱。
6. 游戏每天自动保存；也可以手动导出存档文本。
